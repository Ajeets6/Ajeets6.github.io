# Ajeet Singh — Portfolio

Personal portfolio and project notes for my work across AI engineering, retrieval,
computer vision, and systems software.

**Live site:** [ajeets6.github.io](https://ajeets6.github.io)

## Featured work

- Multimodal retrieval-augmented generation
- LLM analytics dashboard
- CHIP-8 emulator built with raylib
- Aerial imagery analysis
- Gurmukhi small language model

## Built with

- [Quarto](https://quarto.org/) and Markdown
- Custom SCSS and CSS
- GitHub Pages and GitHub Actions

## Run locally

Install Quarto, clone the repository, then start the development server:

```sh
quarto preview
```

To create a production build in `_site/`:

```sh
quarto render
```

## Deployment

Pushes to `main` are rendered and published to the `gh-pages` branch by the
Quarto Publish GitHub Actions workflow.
